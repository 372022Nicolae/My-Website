Student Info Manager

Overview

A Java command-line application that allows users to add, update, search, and delete student records using Object-Oriented Programming (OOP) principles.

Technologies Used

  • Java (Core OOP, Collections)
  • JUnit 5 (Unit Testing)

Key Highlights

Structured with domain classes, encapsulation for student attributes, and automated unit testing for registry lookups and validation logic.
