Java Knowledge Quiz Engine

Overview

A Java-based quiz tool that reads questions from a file, prompts the user in the console, evaluates answers, and calculates a final score.

Technologies Used

  • Java (File I/O, Scanner)
  • String Parsing & Conditionals

Key Highlights

Parses formatted text input files to construct interactive question sets dynamically with input error handling and automated score reporting.
